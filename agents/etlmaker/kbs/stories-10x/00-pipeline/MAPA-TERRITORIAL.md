### Detalhamento por Domínio

**D01 — Filosofia de Comunidade**
O princípio fundacional: Instagram Stories não é ferramenta de views, é ferramenta de construção de comunidade. O líder de comunidade não faz conteúdo para as pessoas "gostarem" — ele cria conversas que a comunidade quer ter. Fórmula de conteúdo: 80% comunidade/sentimento, 10% educação, ~1% vida pessoal, 0,5% venda direta.

Subtópicos: comunicação massa → comunidade; liderança de comunidade; maquiavel e liderança; os 3 tipos de criadores de conteúdo (coach/motivacional, educativo, só produtos); por que o Stories é superior ao TikTok/Reels para venda.

**D02 — Os 6 Elementos do Método S10X**
Framework central que organiza todo o método:
1. Ideias de Temas
2. Sequências Especiais
3. Dispositivos de Engenharia Social
4. Análise Pragmática
5. Crescimento de Seguidores
6. Inbox Lucrativo

**D03 — Ideias de Temas (Limitação Criativa)**
Método para gerar 50-300+ temas por sessão usando categorias. Parte-se de grandes categorias (copy, tráfego, comportamental, etc.) e desdobra-se em ideias específicas dentro de cada categoria. O app guarda os temas para uso futuro.

Subtópicos: categorias de tema; banco de temas no app; temas como unidade organizadora da sequência; um tema mantém o público "vidrado" o dia todo.

**D04 — Tipos de Sequências (12 tipos)**
1. Venda de produto (digital)
2. Venda de produto físico
3. Consciência de produto
4. Engajamento público
5. Publicidade (publi)
6. Promoção de parceiro
7. Aquecimento para pico de vendas/lançamento
8. Pré-abertura
9. Caixinha por tema
10. Caixinha geral
11. Evento
12. Divulgação de conteúdo

**D05 — Dispositivos de Engenharia Social (37 dispositivos)**
Gatilhos psicológicos numerados e nomeados. São o nível mais granular do método — estão dentro de cada Stories individual, dentro de uma sequência, dentro de um tema. Analogia do autor: campanha → conjunto de anúncio → anúncio → cópia = tema → sequência → stories → dispositivo.

**D06 — Análise Pragmática / Debriefing**
Framework para medir e reutilizar o que funciona. Documentar cada sequência com notas. Identificar sequências vencedoras para repetir e amplificar (ex: transformar em vídeo, impulsionar).

**D07 — Crescimento de Seguidores**
Técnica de impulsionamento pago para crescer seguidores com perfil similar ao público atual. ROI calculável.

**D08 — Inbox Lucrativo (SpinLadeirinha)**
Adaptação do Spin Selling de Neil Rackham para vendas via inbox do Instagram. Princípios: vender não é empurrar produto; é orientação e ajuda na tomada de decisão. Perguntas nas 4 dimensões: Situação, Problema, Implicação, Necessidade.

**D09 — Aplicativo Stories 10x**
Ferramenta que implementa o método. Funcionalidades: cadastro de produtos e links traqueados, cadastro de parceiros, banco de temas com categorias, criação e planejamento de sequências por tipo, debriefing de resultados.

## 6. Glossário Preliminar

| Termo | Definição |
|-------|-----------|
| **Stories 10x (S10X)** | O método completo de comunicação e venda via Instagram Stories criado por Leandro Ladeira |
| **Dispositivo de Engenharia Social** | Gatilho psicológico numerado (1-37) inserido dentro de um Stories para aumentar engajamento, participação ou venda |
| **Sequência** | Conjunto ordenado de Stories publicados no mesmo dia sobre um tema, seguindo uma lógica testada |
| **Tema** | Assunto central que organiza uma sequência. Ex: "A família não me apoia", "Filhos gastam dinheiro" |
| **Limitação Criativa** | Método de geração de temas: parte de categorias amplas para chegar a temas específicos e infinitos |
| **Combustível Extra** | Dispositivo #1: trazer audiência de outras plataformas (YouTube, Twitter, live, e-mail, Telegram) para os Stories |
| **Conversa Sem Privacidade** | Dispositivo #3: usar conversas do inbox como conteúdo público (ocultando nome/foto se necessário) |
| **Ansiedade pela Abertura** | Dispositivo que cria antecipação para um link, produto ou informação que será liberado em horário específico |
| **Piada Interna** | Dispositivo que cria jargões e memes exclusivos da comunidade, fortalecendo senso de pertencimento |
| **Peça Compartilhamento** | Dispositivo #21: pedir que o público compartilhe o Stories com alguém específico, aumentando alcance orgânico |
| **Abertura de Carrinho** | Dispositivo #11: abrir vendas de produto/evento diretamente via Stories, gerando pico de visualizações |
| **Análise Pragmática** | Processo de debriefing de sequências: medir resultados, anotar o que funcionou, decidir se repete ou amplifica |
| **Inbox Lucrativo** | Módulo e técnica de transformar mensagens recebidas no direct em vendas usando SpinLadeirinha |
| **SpinLadeirinha** | Adaptação do Spin Selling para inbox: perguntas de Situação, Problema, Implicação e Necessidade |
| **Ultra-engajados** | Seguidores que participam ativamente das sequências (mandam prints, fazem desafios). Geram valor para toda a comunidade |
| **Pico de vendas** | Período de intensificação de vendas sem lançamento clássico (produto perpétuo com alta temporária) |
| **Sequência vencedora** | Sequência que gerou alto engajamento/vendas e pode ser repetida ou amplificada |
| **Aquecimento** | Tipo de sequência que prepara o público para uma compra futura (pico de vendas ou lançamento) |
| **Caixinha** | Tipo de sequência baseada em caixa de perguntas do Instagram, por tema ou geral |
| **Engajamento puro** | Sequência sem objetivo de venda imediata — foco exclusivo em criar conexão e participação |
| **Debriefing** | Análise pós-sequência: o que funcionou, quantas respostas, quais dispositivos trouxeram mais resultado |
| **Combustível Extra Combinado** | Variação do Combustível Extra onde múltiplos canais externos direcionam para os Stories ao mesmo tempo |
| **Desafio Curto com Promessa de Análise** | Dispositivo #2: lançar um desafio simples para o público participar, com promessa de análise/feedback |
| **Piada Interna** | Referências, memes e jargões exclusivos que só quem acompanha a comunidade entende |
