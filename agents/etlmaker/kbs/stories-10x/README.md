## O que é esta KB

Knowledge Base completa do curso **Stories 10x** — a estratégia de comunicação e venda via Instagram Stories criada por Leandro Ladeira. O método transforma o Instagram Stories de ferramenta de views em ferramenta de construção de comunidade ativa que compra, engaja e cresce.

**Palavra-chave central:** COMUNIDADE — não views.
