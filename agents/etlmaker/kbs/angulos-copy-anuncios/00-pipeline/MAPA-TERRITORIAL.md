## 2. Backbone

- `backbone_exists`: **sim**
- `backbone_description`: o autor organiza o método em duas espinhas que se completam:
  1. **A planilha**: 4 categorias por nível de consciência (Problema → Solução → Produto → Oferta) + Genéricos. É a mesma espinha das bibliotecas de Provas e de Objeções (as mesmas 4 abas) e das 4 estruturas-padrão de anúncio (SRC-07).
  2. **O processo de 6 etapas** (SRC-13/06): Briefing → Ângulos → Estrutura → Formatos → Multiplicação → Métricas.
  3. As **3 alavancas** (SRC-07) amarram tudo: mecanismo (produto), formato (copy) e ângulo/nível (tráfego).
- `backbone_source`: SRC-08 (categorias), SRC-13 (processo), SRC-07 (alavancas)
- `strategy`: **use_author_backbone**
- `justification`: autor único, método explícito e repetido em 4 fontes. Os volumes seguem a ordem natural do método: entender (fundamentos) → escolher o ângulo (catálogo) → montar o anúncio (estrutura + provas/objeções + mecanismo) → embalar (formato) → produzir e rodar (máquina + campanha).

## 6. Glossário Preliminar

| Termo | Definição (no uso do autor) |
|-------|------------------------------|
| Ângulo | Ponto de vista central pelo qual o anúncio inteiro fala do problema, da solução, do produto ou da oferta |
| Nível de consciência | Estágio do público (Schwartz): inconsciente, consciente do problema, da solução, do produto, totalmente consciente |
| Sofisticação de mercado | Quantas promessas parecidas o público já viu (estágios 1–5 no FORJA) |
| Ângulos genéricos | Ângulos de formato/atenção que servem a qualquer nível (curiosidade, polêmica, desafio, analogia, psicologia reversa…) |
| Formato | Embalagem da mensagem para parecer conteúdo orgânico (caixinha, react, tela dividida, diálogo, WhatsApp…) |
| Gancho (hook) | O que para o scroll de um público específico nos 3–5 primeiros segundos: visual (formato), textual (headline) e falado |
| Headline | Texto parado no meio da tela (não é legenda), em fonte nativa, com contexto + nível de consciência |
| Hook rate | Visualizações de 3 s ÷ impressões; mede gancho e formato |
| Corpo | Parte do meio do anúncio: provas e quebras de objeção |
| CTA | Chamada para ação com motivo e com o que acontece depois do clique |
| Estrutura | Quais blocos de persuasão entram no anúncio e em que ordem |
| Estrutura invisível | A ordem dos elementos de persuasão; o anúncio como Lego |
| Megazord | Anúncio montado juntando peças prontas (gancho, corpo, CTA) ou trecho de vídeo antigo com gancho novo |
| Estrutura-padrão | Esqueleto fixo por categoria (problema, solução, produto, oferta) adaptado a todos os ângulos dela |
| Multiplicação | Ângulo × estrutura × formato = anúncio único |
| Briefing | Levantamento prévio de todos os argumentos e informações do público |
| Benefício funcional / dimensional / emocional | Óbvio / consequência na vida real (aula 02) ou quanto-quão rápido (briefing) / o que a pessoa sente |
| Objeções (5) | Tempo, dinheiro, esforço, conhecimento, risco |
| Elementos de credibilidade | Demonstração, resultado, prova social, reason why, autoridade, estudo, humildade, reconhecer o ceticismo, reduzir a promessa |
| Prova social × resultado | Prova social = muita gente já fez; resultado = o resultado de alunos ou próprio |
| Admissão prejudicial | Admitir uma limitação real do produto antes que perguntem |
| Mecanismo (único) | A solução, mas única: explica POR QUE resolve; "o veículo" (Brunson) |
| Mecanismo do problema / da solução | A causa raiz do problema / a solução que combate essa causa |
| UMP / UMS | Unique Mechanism of the Problem (o vilão) / of the Solution (o caminho) — FORJA |
| One Belief | "[Nova oportunidade] é a chave para [desejo] — e só é alcançável através de [meu mecanismo]" |
| Genesis story | História de origem do mecanismo: descobridor + acidente/obsessão + atrito + "por que nunca ouvi falar?" |
| Lista negra | Mecanismos já queimados no nicho |
| Alavanca | Pequeno esforço que gera grande resultado (80/20) |
| Time campeão / anúncio campeão | Campanha como seleção de anúncios com funções diferentes × busca do anúncio que vende sozinho |
| Zagueiro | Anúncio que não converte direto mas eleva a consciência para outro converter |
| Escala lateralizada | Subir/baixar 25% da verba de todas as campanhas conforme o CPA, sem duplicar |
| Relevância estatística | Dados mínimos para decidir (≥100 cliques, ≥3 dias) |
| Limitação criativa | Restringir as escolhas para facilitar a criação ("diga 5 carros") |
| Segmentação pelo criativo | O conteúdo do anúncio (palavras, imagens, nomes) define para quem a plataforma entrega |
| Safe zone | Área central do vídeo, livre dos botões da interface |
| UGC / "GC" | Conteúdo gravado por terceiro como se fosse cliente |
| Testemunha adversa | Ângulo citado por aluno (especialista destrói uma crença); fora da planilha |

## 10. Problemas / Gaps / Contradições

**Contradições (registradas, não resolvidas):**
1. **Qual é o 80/20 da copy.** Aula 05 [01:16:48; 01:25:41]: "o 80/20 da copy é o mecanismo; o 80/20 do anúncio é o formato". Aula 07 [12:49]: "o 80/20 da copy é o formato", e o mecanismo é a alavanca do PRODUTO. A ideia de fundo é a mesma (mecanismo + formato pesam mais), mas a classificação muda.
2. **Ângulo é de copy ou de tráfego.** Aulas 01–03 tratam ângulo como peça de copy; aula 07 [26:02] diz que "ângulo é uma alavanca de tráfego, não de copy" (e completa que também importa para a persuasão).
3. **Testar e matar perdedores × nunca desativar.** SRC-13: "mate os perdedores sem apego", e aula 06 recomenda campanha de teste 1-1-1 a R$ 10/dia. Aula 07: "eu não faço teste de anúncios", "não desativo nenhum anúncio", "olho a métrica da campanha".
4. **Mídias relacionadas.** Aula 05 descreve que usa 1 anúncio com 10 mídias relacionadas; aula 06 diz que faz isso mas "não recomenda" (perde a métrica individual).
5. **Ângulo × gancho.** Aula 06 [20:51]: "o ângulo é muito próximo ao gancho"; aula 07 [26:33]: "ângulo também não é o gancho".
6. **Benefício dimensional.** Aula 02: consequência na vida real (carro, plano de saúde). Briefing (SRC-14): "quanto, quão rápido, com que frequência".
7. **Advantage aberto.** Contraponto de aluno advogado (high ticket): restringir público/idade/região funcionou melhor. O autor mantém "segmentar pelo criativo", mas reconhece que existem outras formas.
