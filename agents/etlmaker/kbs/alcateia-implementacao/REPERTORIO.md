## FÓRMULAS

### Fórmula da Promessa Matadora
```
[PÚBLICO ESPECÍFICO] + [PROBLEMA DE 90 DIAS] + [MECANISMO ÚNICO] = PROMESSA

Exemplo:
"Ajudo [psicólogos] a [faturar R$5k/mês em mentorias pelo WhatsApp] 
[sem gravar vídeos e sem precisar de audiência] nos primeiros 90 dias."
```

### Fórmula do Bio do Instagram
```
Linha 1: [Resultado] para [quem]
Linha 2: [Número de prova] | [Método/Autoridade]
Linha 3: [CTA] + [Link]
```

### Fórmula da Escada de Tráfego
```
R$10/dia = ~R$1.500/mês
R$20/dia = ~R$5.000/mês
R$30/dia = ~R$7.000/mês
R$80/dia = ~R$10.000/mês
R$150/dia = ~R$15.000/mês
R$200/dia = ~R$20.000/mês
```

### Fórmula de Escala Flutuante
```
Lucro → aumentar 30%
Empate → manter
Prejuízo → reduzir 20%
```

### Fórmula de Divisão de Verba (remarketing)
```
80% do orçamento → aquisição (turbinar para público frio)
20% do orçamento → remarketing (público que já engajou)
```

### Caminho 30k
```
Fase 1 (R$0-10k): VALIDAR
  - Vender individual (1:1)
  - Coletar depoimentos
  - Validar script de venda
  
Fase 2 (R$10-20k): PREVISIBILIDADE
  - Mini treinamento ou VSL rodando
  - ManyChat configurado
  - 3-5 posts/semana consistentes
  
Fase 3 (R$20k+): ESCALA
  - Tráfego pago escalado
  - Remarketing ativo
  - Recorrência funcionando
```

### CRM de Leads
```
Abordagem inicial → sem resposta em 24h → FOLLOW-FRIO
  (3 mensagens em 3 dias → arquivo)

Respondeu → mapeamento → sem resposta → FOLLOW-MORTO
  (reativar após 15 dias com produto R$200)

Chegou na oferta → sem resposta → FOLLOW-QUENTE
  (reativar na última semana do mês)

Fechou → GANHOU

Não fechou após preço → PERDEU
  (downsell 50% do valor após 15 dias)
```

### Estrutura VSL — 29 Atos
```

  1. Quebra gelo

  3. Benefícios
  4. Reversão de objeções
  5. Prova
  6. Para quem é

  17. Urgência
  18-20. Bônus 1, 2, 3

  23. Reversão Psicológica ("sem dinheiro")
  24. Revelação do Preço
  25. Condições de Pagamento
  26. CTA Principal
  27. Depoimentos
  28. Segundo CTA
  29. Pós-crédito
```

### Protocolo WhatsApp (Carol)
```
ABORDAGEM
  "Olá, tudo bem? Não sei se você notou, mas se se interessou em 
  escalar seu conhecimento digital — tenho algo que pode acelerar 
  esse processo. Me fala sobre o seu negócio."
      ↓
MAPEAMENTO (4 perguntas adaptáveis)
  • Você é especialista em algo hoje?
  • Qual seu ticket atual de venda?
  • Qual sua meta de faturamento?
  • Qual sua maior dificuldade?
      ↓
  [Com case] / [Sem case]
      ↓
  "Minha indicação é você entrar para [mentoria].
  Se fizer sentido investir agora, me dá um ok que 
  te mando detalhes do programa."
      ↓
OFERTA (após o "ok")
  1. Objetivo do programa
  2. Os 4 pilares
  3. Entregáveis
  4. "Está dentro do que você busca?"
      ↓
INVESTIMENTO
  "[Preço cheio]. Entrando hoje: [desconto].
  [Condições de pagamento]."
```


### Funil de Zoom (Funil de Aula) — 4 Etapas
```
1. NARRATIVA   → Grande Motivo + Grande Promessa + Única Ação (CTA)
                 (aparece em TODO conteúdo de captação)
2. CAPTAÇÃO    → orgânico (stories 3x/sem + feed) ou pago → página de captura
                 Página de obrigado SEM link → link do grupo só via WhatsApp
3. AULA (~1h)  → modelo Conversão Imediata (ver estrutura abaixo)
4. VENDAS      → fluxo de disparos via WhatsApp ao longo da semana
                 Efeito bola de neve: base de leads cresce a cada ciclo
```

### Estrutura da Aula de Conversão Imediata (spoiler do pitch no meio)
```
TEMA CENTRAL (objetivo, não subjetivo — resultado palpável)
    ↓
1. Estrutura/Narrativa  → o "porquê" da entrega
    ↓
2. Execução             → o "como", passo a passo
    → SPOILER DO PITCH (1-2 frases) no fim desta etapa = pico de audiência
    ↓
3. Prática              → mão na massa
    ↓
4. Prova Racional + PITCH ESTENDIDO → números que provam o resultado + oferta completa
```

### Fluxo Semanal de Disparos (Funil de Zoom)
```
FLUXO PADRÃO (mínimo):
  Domingo  → anuncia o tema + lembrete
  Segunda  → lembrete
  Terça    → "hoje é o link, começamos" (dia da aula)

FLUXO COMPLETO (extensão):
  + Quarta → replay da aula
  + Quinta → reunião de vendas / tira-dúvida
  + Sexta  → segunda oferta (downsell / quebra de objeção de preço)
```

## SCRIPTS

### Script de Abordagem Social Selling (Instagram)
```
"Vi que você respondeu meus Stories. Está interessado em [mentoria/produto]?
Consegue me chamar no WhatsApp?"
```

### Script Método Cedo — Diagnóstico em Áudio
```
"Tudo bem, [nome]. Cara, eu entendi que o caminho ideal para você é [solução].
Vou te mostrar todo o meu framework — como [resultado específico] 
nos próximos [prazo].

Você vai ter [entregável 1], [entregável 2] e de bônus [bônus específico].

Se fizer sentido investir em uma mentoria agora, me manda um ok 
que te mando os detalhes da proposta."
```

### Script de Reativação Follow-Morto (15 dias)
```
"Lembrei de você. Hoje [nome], estou avaliando alguns projetos.
Quero compartilhar com você uma novidade — desenvolvi essa solução
com base no feedback de alguns clientes. Posso te mandar detalhes?"
```

### Script de Reativação Follow-Quente (última semana do mês)
```
"Vi que você recebeu uma oferta da [mentoria] e ainda não fechou.
Posso te enviar a proposta?"
```

### Script Boas-vindas Social Selling (1 — atrasado)
```
"Oi [nome], ainda não tinha dado boas-vindas — erro meu!
Faz tempo que te sigo.
Espero que meu conteúdo de [nicho] possa agregar na sua jornada.
Seja bem-vindo!"
```

### Script Boas-vindas Social Selling (2 — novo seguidor)
```
"Oi [nome], seja bem-vindo!
Ajudo [público] a [resultado].
Espero que meu conteúdo agregue e tamo junto."
```

### Script Boas-vindas Social Selling (3 — visita sincera)
```
"Oi [nome], tudo bem? Passando para dar boas-vindas.
Espero que meu conteúdo agregue na sua jornada.
Vi que você é especialista em [área] — parabéns pelos posts, muito bom.
Ótimo dia para você."
```

### Script de Apresentação de Preço (com escassez)
```
"O investimento da [mentoria] é [preço cheio].
Entrando hoje: [preço com desconto].
[Condições de parcelamento].

Qual das condições de pagamento está dentro do seu orçamento?"
```
