## 1. CILINDRO DE VENDAS — O MODELO ATUAL

### O modelo antigo vs. o modelo atual

| Modelo Antigo (escada) | Modelo Atual (cilindro) |
|-----------------------|------------------------|
| Grátis → Low ticket → Mid → High | Universo ao redor de 1 produto core |
| Cliente "sobe" de produto | Cliente entra no nível certo |
| Jornada longa, muitos pontos de fricção | 2 funis de entrada, múltiplos níveis |
| Depende de conteúdo grátis para converter | Funil qualifica antes de chegar na oferta |

### O Cilindro na prática

```
PERFIL INSTAGRAM
    ↓
[Conteúdo / Stories / Tráfego]
    ↓
┌─────────────────────────────┐
│    CILINDRO DE VENDAS       │
│                             │
│  ┌──────────────────────┐  │
│  │  MINI TREINAMENTO    │  │
│  │  (5-10 min)          │  │
│  └──────────┬───────────┘  │
│             ↓               │
│  ┌──────────────────────┐  │
│  │  AULA MILIONÁRIA     │  │
│  │  (VSL 20-25 min)     │  │
│  └──────────┬───────────┘  │
└─────────────┼───────────────┘
              ↓
    [WhatsApp OU Checkout]
              ↓
       VENDA FECHADA
```

### Os 2 funis de entrada

| Funil | Produto de entrada | Fluxo | Ticket alvo |
|-------|------------------|-------|-------------|
| **Mini Treinamento** | Vídeo 5–10 min | Comentar → ManyChat → mini treinamento → WhatsApp | R$1.000–R$3.000 (mentoria) |
| **Aula Milionária (VSL)** | Vídeo 20–25 min | Comentar "relatório" → ManyChat → VSL → checkout | R$197–R$497 (infoproduto) |

## 2. JORNADA DO CLIENTE

A jornada completa de um lead desde o primeiro contato até a compra:

```
1. Vê conteúdo no feed/stories
         ↓
2. Comenta com palavra-chave (ou responde story)
         ↓
3. ManyChat entrega o link via DM
         ↓
4. Entra no mini treinamento OU na aula milionária
         ↓
5. Vai para WhatsApp (mentoria) OU checkout (infoproduto)
         ↓
6. Compra
```

**Variações da entrada:**
- Reels com CTA para comentar "aula" → ManyChat → mini treinamento
- Post carrossel com CTA para comentar "relatório" → ManyChat → VSL
- Story de levantada de mão → DM direta → WhatsApp
- Tráfego pago → mini treinamento ou VSL diretamente

## 3. MINI TREINAMENTO

### O que é e para que serve

O mini treinamento é um vídeo de **5–10 minutos** que qualifica o lead para receber uma oferta de produto de ticket médio-alto (R$1.000–R$3.000).

**Não é um curso gratuito.** É uma peça de venda disfarçada de conteúdo de valor.

### Estrutura do Mini Treinamento

| Parte | Duração | O que fazer |
|-------|---------|-------------|
| **Abertura** | 0–1 min | Quebrar gelo + prometer resultado específico em X minutos |
| **Conteúdo** | 1–6 min | Mostrar os 4 pilares + prova racional (resultado possível) |
| **Pitch** | 6–10 min | Apresentar a mentoria + CTA para WhatsApp |

### Métricas de mini treinamento

| Métrica | Meta | O que fazer se não atingir |
|---------|------|--------------------------|
| **Retenção @30s** | 60–70% | Melhorar abertura (primeiros 30s determinam tudo) |
| **Retenção @pitch** | 20–30% | Conteúdo não está qualificando — rever pilares |
| **Velocidade sugerida** | 1.1–1.2x | Já vem configurado no VTurb |

### Planilha de ROI do Mini Treinamento

Exemplo validado por Vini (aula 45):

| Variável | Valor |
|---------|-------|
| Custo por comentário | R$6 |
| Leads para comentar | 100 |
| Investimento total | R$600 |
| Taxa de compra (sem reunião) | ~10% |
| Vendas a R$997 | ~10 vendas |
| Faturamento | R$9.970 |
| **Lucro** | ~R$9.370 |
| Com reunião comercial (30% conv.) | Pode chegar a R$20.000+ |

## 4. MANYCHAT (MINICHAT) — AUTOMAÇÃO DE COMENTÁRIOS

### Como funciona

O ManyChat monitora comentários com uma palavra-chave específica e automaticamente envia uma DM com o link do funil.

### Fluxo completo de automação

```
Usuário comenta "aula" no post
    ↓
ManyChat detecta a palavra-chave
    ↓
Envia DM: "Aqui está sua aula: [link]"
    ↓
Aguarda 14 minutos
    ↓
Follow-up: "O link funcionou para você?"
    ↓
Aguarda 23 horas
    ↓
Remarketing: "Ei, você chegou a assistir?"
    ↓
Opcionalmente: áudio de follow-up (aumenta conversão)
```

### Configuração do fluxo

| Elemento | Configuração |
|---------|-------------|
| **Gatilho** | Palavra-chave no comentário (ex: "aula", "relatório") |
| **Primeira mensagem** | Entrega do link imediata |
| **Follow-up 1 (14 min)** | "O link funcionou?" |
| **Follow-up 2 (23h)** | Remarketing com nova mensagem |
| **Randomizador** | 3–4 variações de mensagem (evita bloqueio do algoritmo) |
| **Áudio de follow-up** | OGG convertido para M4A via convert.io (aumenta conversão ~30%) |

### Hack de aumento de conversão +30%

Trocar a mensagem de follow-up de 24h por **áudio** aumenta a conversão em aproximadamente 30%.

**Como fazer:**
1. Gravar áudio de follow-up (30–60 segundos)
2. Converter OGG para M4A via convert.io
3. Subir no ManyChat como áudio
4. Usar randomizador com 3–4 audios diferentes

> O áudio cria uma sensação de contato pessoal — o lead sente que está falando com uma pessoa real, não com um bot.

### Troubleshooting comum

- **Automação não disparando:** verificar permissões de mensagens na conta do Instagram (ativar em Configurações → Privacidade → Mensagens)
- **Comentários sendo filtrados:** Instagram pode esconder comentários com links — usar palavra-chave sem link no comentário
- **Taxa de DM baixa:** testar variações de gatilho e verificar se post está com comentários públicos habilitados

## 5. AULA MILIONÁRIA (VSL) — OS 29 ATOS

### O que é

A Aula Milionária é um VSL (Video Sales Letter) de **20–25 minutos** que vende um infoproduto de R$197–R$497 diretamente pelo checkout, sem reunião comercial.

**Diferença do Mini Treinamento:**
- Mini treinamento → fecha via WhatsApp (mentoria hi-ticket)
- Aula Milionária → fecha via checkout (infoproduto mid-ticket)

### Métricas de VSL

| Métrica | Meta | Se não atingir |
|---------|------|---------------|
| **Retenção @1 min** | 70% | Reescrever abertura |
| **Retenção @3 min** | 60% | Gancho do intro está fraco |
| **Retenção @pitch** | 20–30% | Conteúdo não está engajando |
| **Taxa de compra** | 15–20% dos que chegam ao preço | Oferta ou preço com problema |
| **Taxa conversão geral** | 2–2.5% (sem depoimentos) / 3–4% (com depoimentos) | Ver seção de depoimentos |

### Estrutura completa — 3 Estágios e 29 Atos

#### ESTÁGIO 1 — INTRO (0–8 min) — 9 Atos

| Ato | Nome | O que fazer |
|-----|------|------------|
| 1 | **Quebra gelo** | Linha que cria conexão imediata — pergunta, provocação ou curiosidade |
| 2 | **Promessa + Gancho** | Resultado específico que o espectador vai ter + motivo para assistir até o fim |
| 3 | **Benefícios** | 3–5 benefícios concretos do que vem a seguir |
| 4 | **Reversão de objeções** | Antecipar e resolver as 2–3 maiores objeções de adesão ("isso é para mim?") |
| 5 | **Prova** | Prova social ou resultado pessoal — demonstra que o método funciona |
| 6 | **Para quem é** | Definir explicitamente o público — inclui e exclui |
| 7 | **Play Open** | Anunciar que haverá oferta ao final — prepara a mente para comprar sem ser pego de surpresa |
| 8 | **Loops** | Criar perguntas não respondidas que o espectador só vai resolver assistindo até o fim |
| 9 | **Quem você é** | Autoridade — por que você é a pessoa certa para ensinar isso |

#### ESTÁGIO 2 — CONTEÚDO (8–20 min) — 4 Atos

| Ato | Nome | O que fazer |
|-----|------|------------|
| 10 | **Problema Único** | O problema específico que o cliente está enfrentando — descrito com as palavras dele |
| 11 | **Solução Única (Mecanismo)** | Como o método resolve o problema de forma exclusiva |
| 12 | **Mapa de 4 Passos** | Os 4 pilares da metodologia explicados com profundidade suficiente para provar competência |
| 13 | **Brilho Final** | Prova racional — dado, case, resultado que fecha o argumento "isso funciona" |

#### ESTÁGIO 3 — OFERTA (20–25 min) — 16 Atos

| Ato | Nome | O que fazer |
|-----|------|------------|
| 14 | **Transição** | Conectar o conteúdo com a oferta — "agora eu vou te mostrar como ter acesso a tudo isso" |
| 15 | **Amplificação** | Ampliar o desejo — o que fica mais fácil, mais rápido, mais garantido com o produto |
| 16 | **Empilhamento de Preço** | Mostrar o valor de cada componente separado > depois revelar o preço do pacote |
| 17 | **Urgência** | Por que decidir agora (vagas, prazo, bônus por tempo limitado) |
| 18 | **Bônus 1** | Primeiro bônus que remove objeção específica |
| 19 | **Bônus 2** | Segundo bônus |
| 20 | **Bônus 3** | Terceiro bônus (opcional) |
| 21 | **Garantia** | 30 dias sem burocracia — "se não gostar, devolvemos" |
| 22 | **FAQ** | 3–5 perguntas frequentes de objeção (investimento, tempo, funciona para mim?) |
| 23 | **Reversão psicológica** | "Sem dinheiro" — reencadrar o custo de não agir vs. custo do produto |
| 24 | **Revelação do Preço** | Preço cheio → "mas hoje" → preço com desconto |
| 25 | **Condições de Pagamento** | Opções de parcelamento |
| 26 | **CTA Principal** | Instrução clara de como comprar (botão aparece nesse momento no GreatPages) |
| 27 | **Depoimentos** | 2–3 depoimentos curtos de clientes (aumenta conversão 3–4% vs. 2–2.5%) |
| 28 | **Segundo CTA** | Repetir a instrução de compra após depoimentos |
| 29 | **Pós-crédito** | Encerramento com última provocação + tela preta com CTA em texto |

### VSL com e sem depoimentos

| Versão | Taxa conversão | Quando usar |
|--------|---------------|-------------|
| **Sem depoimentos** | 2–2.5% | Produto novo, sem clientes ainda |
| **Com depoimentos** | 3–4% | Após ter 2+ resultados de clientes |

**Onde inserir depoimentos:** após a reversão psicológica (ato 23), antes do segundo CTA.

## 6. PLATAFORMAS DO FUNIL

### VTurb — Hospedagem do Vídeo

O VTurb é a plataforma de hospedagem do VSL. Configurações obrigatórias:

| Configuração | Como deixar | Por quê |
|-------------|------------|---------|
| **Barra de progresso** | OFF | Evita que o espectador pule para o final sem assistir |
| **Smart Auto Play** | ON | Vídeo começa automaticamente ao abrir a página |
| **Continuar assistindo** | ON | Se a pessoa sair e voltar, retoma de onde parou |
| **Velocidade** | 1.1–1.2x por padrão | Reduz tempo de comprometimento sem perder qualidade |

### GreatPages — Construtor de Páginas

O GreatPages é usado para criar a página do mini treinamento e do VSL.

**Recurso crítico: delay no botão de CTA**

O botão de compra só aparece no momento exato do pitch — não fica disponível desde o início. Isso força o espectador a assistir o conteúdo antes de poder comprar.

| Configuração | O que faz |
|-------------|---------|
| **Delay do botão** | Botão aparece apenas X segundos após início do vídeo |
| **Blocos de texto** | Aparecem em momentos estratégicos conforme o vídeo avança |
| **Template importado** | Usar template pronto da Alcateia (Mentorados L2/L3) |

### Upsell Page

Após a compra do VSL (R$397), apresentar uma oferta de upsell (R$597) imediatamente:

```
Compra VSL a R$397
    ↓
Página de upsell: "Adicione [produto complementar] por apenas R$597"
    ↓
Total combinado: ~R$1.000
```

## 7. ESTRATÉGIA DE CANAIS NO PERFIL

O perfil Instagram funciona como hub de 3 funis simultâneos:

| Canal | CTA do Conteúdo | Palavra-chave | Funil destino |
|-------|----------------|---------------|---------------|
| **Carrossel** | "Comente 'novo' para receber" | novo / aula | Mini Treinamento |
| **Reels** | "Comente 'relatório' para receber" | relatório | VSL (Aula Milionária) |
| **Post Twitter/estático** | "Comente 'zoom' para entrar" | zoom | Live/Webinário |

> Os 3 funis funcionam simultaneamente — o lead entra pelo canal que encontrar primeiro.

### Funil de seguidores via ManyChat

Sequência para aumentar seguidores qualificados antes de entregar o funil:

```
Comentou a palavra-chave
    ↓
ManyChat: "Para receber o vídeo, você precisa me seguir primeiro"
    ↓

    ↓
Seguiu → entrega o link
Não seguiu → lembrete de 24h
```

> **Nota:** Vini usou essa estratégia e depois abandonou por gerar seguidores menos engajados. Válida como tática de caixa rápido, não como estratégia permanente.

### Randomizador de mensagens

Usar 3–4 variações de mensagem no ManyChat evita que o Instagram identifique padrão de spam e reduza a entrega das DMs.

## 10. REGRAS CARDINAIS DO FUNIL

1. **Funil antes de tráfego.** Sem funil funcionando, tráfego só gera custo.
2. **Mini treinamento → WhatsApp → venda (mentoria).** VSL → checkout → venda (infoproduto). Não misturar os fluxos.
3. **Botão aparece só no pitch.** GreatPages com delay — nunca mostrar botão desde o início.
4. **VSL escrito à mão.** ChatGPT não produz autenticidade de voz necessária para converter.
5. **Depoimentos dobram a conversão.** Prioridade alta após ter 2+ clientes com resultado.
6. **Áudio de follow-up aumenta 30%.** Investimento de 1 hora de gravação recuperado na primeira semana.
7. **Comentários ManyChat = dividir por 2.** A automação responde, duplicando o número bruto.
