## 3. Benchmarks

| Métrica | Valor de Referência |
|---|---|
| Sinal de qualidade de frase viral (TikTok) | +30 mil curtidas |
| Jornada de pontos de contato até decisão de compra (pré-2021) | 7 pontos |
| Jornada de pontos de contato até decisão de compra (hoje) | 28 pontos (média de mercado) |
| Proporção Reels de venda direta | Máximo 10% da produção |
| Proporção Stories rotina/venda | 80% / 20% |
| Visualizações médias de Stories da autora | 38-40 mil |
| Origem das visualizações do perfil | 80% Reels, 16,8% Stories |

## 5. Workflows

### Método TikTok de Curadoria de Ideias

Abrir TikTok → pesquisar tema → Filtros → Contagem de Curtidas → identificar padrão → pegar gancho, trazer opinião própria.

[Fonte: 02-ideias-infinitas.txt]
*Contextualizado em: [VOL-02, Seção 2](VOL-02-os-cinco-codigos-virais.md#2-como-ter-ideias-infinitas-o-método-tiktok)*

### Diagnóstico de Retenção via Instagram Insights

Ver postagem → Insights → observar % de retenção → identificar momento de saída → diagnosticar (início=gancho fraco, meio=falta impacto, final=está funcionando).

[Fonte: 02-retencao-que-hipnotiza.txt]
*Contextualizado em: [VOL-03, Seção 2](VOL-03-roteiros-virais.md#2-retenção-que-hipnotiza-o-meio-do-vídeo)*

### Maximizando Alcance de Stories

Postar primeiro uma foto (não vídeo) com pergunta → aguardar resposta → postar o restante da sequência.

[Fonte: 02-codigo-bombar-stories.txt]
*Contextualizado em: [VOL-04, Seção 2](VOL-04-movimento-stories-posicionamento.md#2-o-código-de-bombar-stories)*

### Edição CapCut — Corte Básico (usado em Loufai, Vogue, Frases)

Dividir → excluir trecho indesejado → repetir até montar sequência final → adicionar texto/legenda → exportar.

[Fonte: 03-codigo-1.txt, 05-codigo-3.txt, 06-codigo-4.txt]
*Contextualizado em: [VOL-02](VOL-02-os-cinco-codigos-virais.md)*

### Edição CapCut — React (Tela Dividida)

Baixar vídeo viral → Novo projeto → Camada → Adicionar camada → arrastar/reposicionar pra dividir tela → legenda automática ou manual.

[Fonte: 04-codigo-2.txt]

Uma página com ~1 milhão de seguidores, de posicionamento oposto ao da Clara, reposta rotineiramente os vídeos dela — gerando alcance adicional através da audiência dessa página rival.
