## O QUE É ESTA KB

Knowledge base de estratégia de lançamento extraída das 5 aulas disponíveis do Desafio Jejum 5em7 (Bônus + Aulas 1-5). O objetivo não é documentar o conteúdo das aulas — é extrair a inteligência por trás de como o lançamento foi construído: narrativa, método, oferta e engajamento.

**Criada para:** Lives da Karol analisando estratégias de lançamento de outros experts.

**Fontes:** Transcrições automáticas (yt-dlp) das aulas públicas do desafio, convertidas via pipeline ETL.

**Aulas 6 e 7:** Ainda não disponíveis (releases 20/06 e 21/06). Merge mode disponível quando publicadas.
