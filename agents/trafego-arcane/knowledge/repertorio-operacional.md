## 2. Checklists

### Checklist Publicos (pre-campanha)

**Quentes:** IG Engagement (30/60/90/180/365D), FB Engagement (30/180/365D), PageView (30/180D), VideoView 50% (365D), Lista Emails, Lista Compradores, Audiencia Completa

**Especiais (Pixel):** Checkout (7/30/180D), Purchase (30/180D), Lead (30/180D)

**Frios:** Aberto, Demografico, Interesses diretos (max 5/conjunto), Interesses relacionados, LAL 1% compradores, LAL 1% IG, LAL 1% PageView

**Rotina:** Atualizar VideoView semanalmente (marcar videos novos).

### Checklist Setup Inicial

- [ ] Conta de ESCALA e conta de TESTE criadas
- [ ] Pixel instalado no site
- [ ] Eventos: PageView, ViewContent, Lead, InitiateCheckout, Purchase
- [ ] Conversoes personalizadas por produto
- [ ] Colunas do gerenciador personalizadas
- [ ] Publicos de audiencia quente criados
- [ ] Limitacao de localizacao (negocio local)

### Checklist Producao Criativa

| Fase | Itens |
|------|-------|
| Antes | Definir objetivo, formato, fala/musica, imagens fundo branco, roteiro, ferramentas |
| Durante | Consistencia personagem, hack idioma, aspas duplas p/ fala, testar 2 opcoes |
| Edicao | Cortar tremidas, musica volume baixo + royalty free, verificar textos, CTA visual |
| Entrega | Min 9 criativos, OBRIGATORIO video + estatico, diversidade real (nao trocar cor) |

### Checklist Otimizacao Diaria

| Quando | Acao |
|--------|------|
| Diario | Verificar metricas, pausar anuncios com CPA > limite |
| Campanha boa | Escalar 20-50%/dia (vertical) |
| Campanha ruim | Novos criativos > CPA max > novo conjunto |
| Criativos novos | Testar na conta de teste primeiro (se >9) |
| NUNCA | Duplicar campanhas na escala / Mexer no que esta bom |

### Checklist Contingencia

- [ ] 3-4 perfis administradores backup em cada BM
- [ ] Email profissional em toda a estrutura
- [ ] BMs adicionais criadas
- [ ] Dominios backup registrados
- [ ] Contas de anuncio backup criadas
- [ ] Documentacao de recuperacao preparada

## 3. Benchmarks Consolidados

### Metricas

| Metrica | Benchmark | Nota |
|---------|-----------|------|
| CPA | Depende do negocio | Metrica rainha — se bom, ignora o resto |
| CTR | > 2% | > 4% em LATAM |
| Connect Rate | 70-80% | Abaixo = site lento |
| Conversao LP lead | > 30% | "Isso e lei" |
| Conversao LP vendas | 2-3% | Qualquer produto/preco |
| Conversao e-commerce | > 1% | Mais baixo pela natureza |
| Frequencia anuncio | max 2 | Acima = mais criativos |
| Frequencia campanha | Quanto mais, melhor | Remarketing automatico |
| Discrepancia ger./CRM | ate 15% | Acima = verificar pixel/API |
| Pesquisa preenchida | 60-80% | Na pagina de obrigado |
| Entrada grupo WA | > 70% | Com pesquisa pode cair 5-10% |

| Parametro | Benchmark |
|-----------|-----------|
| Criativos/conjunto | 9 (3xC1 + 3xC2 + 3xC3) |
| Orcamento max inicial/conjunto | R$150 / US$50 |
| Escala diaria | 20-50% |

## 4. Anti-Padroes

### Publicos

| Anti-Padrao | Por que |
|-------------|---------|
| Publico < 100k (sem excecao geografica) | Encarece demais |
| 15+ interesses no mesmo conjunto | Encarece (max 5) |
| LAL 10% | Perde qualidade — sempre 1% |
| Duplicar quente em multiplos conjuntos | Competem entre si |
| Excluir o que nao consegue definir | Exclusao so compradores e leads |
| VideoView por DIAS em vez de percentual | Degrade errado |
| Hipersegmentacao sem criativo dedicado | Triplice incompleta |

### Campanhas e Criativos

| Anti-Padrao | Por que |
|-------------|---------|
| Duplicar pra escalar | Escala = vertical (mais orcamento), nao horizontal |
| CBO sem motivo | ABO e padrao Andromeda |
| Parar campanha boa "pra testar" | Vaca gorda = escalar, nao testar |
| Misturar testes (2+ variaveis) | 1 variavel por teste, senao nao isola |
| So video OU so estatico | OBRIGATORIO mesclar |
| C1 sem C3 (ou vice-versa) | Funil incompleto, 9 criativos = lei |
| Criativos com diferenca minima | Trocar cor da camisa nao conta como diversidade |
| Sem CTA | Todo criativo precisa de CTA claro |
| Remarketing separado | Morto no Andromeda — C1/C2/C3 faz automatico |
| Comecar conjunto > R$150 / US$50 | Pacing quebrado |

### Otimizacao

| Anti-Padrao | Por que |
|-------------|---------|
| Mexer no que funciona | "Nada supera o CPA" |
| Escala horizontal | Criar campanhas novas nao funciona no Andromeda |
| Panico no CPM sazonal | Reduzir orcamento, nao desativar |
| Ignorar pacing | Pressa = mais caro ("piscina em 2 semanas") |
| 6+ meses sem aumentar investimento | Crescer 20% a cada 6 meses |
| Pausar anuncio so por frequencia > 2 | Se CPA ta bom, mantem |

### Infra

| Anti-Padrao | Por que |
|-------------|---------|
| Varios pixels na mesma conta | Confunde rastreamento |
| Evento no lugar errado | Dados sujos, otimizacao errada |
| Sem backup (perfis, BMs, contas) | Contingencia e obrigatoria |
| IG conectado na BM em vez de na Pagina | Erro de vinculacao |
| Sem email profissional | Risco de perda de acesso |
| Pixel sem API de Conversoes | Dados incompletos |

## 5. Estrategias por Orcamento

| Faixa | Foco | Producao Criativos | Testes |
|-------|------|---------------------|--------|
| < R$500 | Vendas puro (kamikaze) + frequencia organica | Quinzenal minimo | Nao testa, roda o que tem |
| R$500-1k | Vendas focado | Quinzenal | 1 teste/mes |
| > R$1k | Vendas + autoridade (seguidores) | Semanal | 1 teste/semana |
| > R$5k | Escala completa + LATAM | Semanal + testes dedicados | 2-3 testes/semana |

**Producao minima por investimento:**

| Investimento | Producao minima |
|-------------|----------------|
| Ate R$5k/mes | 9 criativos quinzenais |
| R$5k-20k/mes | 9 criativos semanais |
| Acima R$20k/mes | 9+ criativos semanais + testes |

**Contas por investimento:**

| Investimento | Contas |
|-------------|--------|
| < R$5k/mes | 1 teste + 1 escala |
| > R$5k/mes | Min 2 teste + 2 escala |

## 6. Estrategias por Nicho

| Nicho | Peculiaridades |
|-------|---------------|
| **E-commerce** | Remarketing por Content ID, ROAS como metrica, catalogo, NAO excluir compradores, conversao min 1%, UGC com IA |
| **Infoproduto** | CPA como metrica, excluir compradores, Boi de Piranha (low ticket R$10-20), formulario se sem site, automacoes abandono + boas-vindas |
| **Negocio local** | Limitacao localizacao a nivel de conta, formulario > site, raio geografico, Engajamento WA > Trafego, Metodo Magneto, CTWA sem LP |
| **Prestador servico** | WhatsApp como CTA, Leads como objetivo, formulario instantaneo, hipersegmentacao por profissao, headline dinamica na LP |
| **Afiliado** | Foco em diversidade de criativos (nao muda produto), UGC com IA, videos review com avatar, hack idioma p/ mercados internacionais, volume > margem |

## 7. Glossario Operacional (termos proprietarios)

| Termo | Significado operacional |
|-------|------------------------|
| **Andromeda** | Conjunto de IAs do Meta que controla algoritmo de anuncios (2025+). Nome do metodo |
| **Santo Graal** | Estrategia central: 2 contas (Teste vs Escala) com mentalidades opostas |
| **C1 / C2 / C3** | Niveis de consciencia dos criativos. C1=baixa, C2=media, C3=alta |
| **Estrela Guia** | Metrica: custo do passo anterior ao CPA. Diagnostica se problema e anuncio ou pagina |
| **Suprassumo** | Encontrar o veio de ouro (gancho/angulo vencedor) e replicar em variacoes |
| **Frankenstein** | Cabeca de um anuncio + corpo de outro + rabo de terceiro = super-anuncio |
| **Tiro de Misericordia** | Oferta final na 4a semana do mes para converter indecisos |
| **Boi de Piranha** | Oferta irresistivel (low ticket R$10-20) que atrai volume para vender no backend |
| **Matar no Ninho** | Pausar conjunto nas primeiras 24h se todos os 9 criativos estao ruins |
| **Contra-Ataque de Panico** | Usar Arvore de Decisao para reagir racionalmente quando metricas assustam |
| **Vaca Gorda / Vaca Magra** | Gorda = periodo bom, ESCALAR. Magra = periodo ruim, TESTAR |
| **Placa-Mae** | Conjunto de anuncios = placa-mae. Se quebrou, perde tudo que estava nele |
| **Achocolatado** | Audiencia Completa: mix de todos os publicos quentes juntos (se cada um < 50k) |
| **Piscina** | Analogia de pacing: pressa custa mais caro (piscina em 2 semanas) |
| **Xavier** | Rastreamento sofisticado WhatsApp: UTM + CRM + redirect diferenciado |
| **Magneto** | Rastreamento bruto WhatsApp: grupos segregados por campanha, manual |
| **Lab vs Fabrica** | Conta Teste = laboratorio (experimentar). Conta Escala = fabrica (produzir) |
| **Caxias** | Mentalidade da conta de escala: seguir cartilha do Meta, obediente |
| **Meter Louco** | Mentalidade da conta de teste: ser transgressor, buscar pepitas |
| **Garanhao** | Criativo que historicamente sempre performou bem |
| **Regra dos 9** | Min 9 criativos ativos por conjunto: 3xC1 + 3xC2 + 3xC3. Inegociavel |
| **Hipersegmentacao** | Triplice: publico especifico + criativo dedicado + LP personalizada |
| **Escada de Campanhas** | Progressao WA: Trafego (volume) > Engajamento (qualificacao) > Vendas (otimizacao) |
| **Arvore de Decisao** | Fluxograma A4: anuncio = binario (CPA bom/ruim), conjunto = complexo |
| **Pontuacao de Oportunidade** | Score 0-100 do Meta. Buscar ~100 na escala, ignorar no teste |
| **Funil API v5** | Anuncio CTWA > WA direto (sem LP) > CRM > Grupo > IA |
