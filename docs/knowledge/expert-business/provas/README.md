# Provas Sociais — Incubadora de Expert (banco de prints e vídeos)

> Prints e vídeos reais de alunas/clientes. Fonte de prova social para carrossel, Reels, LP,
> copy e posicionamento. Transcrições aqui pra a IA achar por busca sem abrir cada imagem.
> Catalogado em: 09/07/2026 · Origem: pasta "Provas" enviada pela Karol.
> Depoimentos resumidos também em `../depoimentos.md`.

## Estrutura

- `imagens/` — prints (PNG/JPG). Leves, versionados no git, usáveis direto como asset de lâmina.
- `videos/` — depoimentos em vídeo (MP4/MOV). **Pesados (~526MB) — NÃO versionados no git**
  (ver `videos/.gitignore`). Ficam no disco/OneDrive como backup. Pra usar num Reels, referenciar
  pelo nome.
