### Gancho falado vs. gancho visual (pergunta da Karol)

Os dados apontam que **os dois trabalharam, em funções diferentes e em sequência**:
- **Gancho VISUAL (imagem do dedo podre)** = o freio do scroll. É pattern interrupt nos primeiros 1-3s — nojo/estranheza param o dedo. O alcance alto (642 contas, distribuição contínua) sugere que a taxa de parada inicial foi boa.
- **Gancho FALADO (pista falsa da fofoca)** = a cola. É o que transforma os 3s em 8s e leva "até o final" (palavra do próprio comentário). Sem a fofoca, o susto visual vira só um scroll-stop sem retenção.

Comparativo interno que sustenta isso: "Esperar seguidores" tinha punch falado forte no segundo zero mas SEM elemento visual — parou em 4s e 482 views. O visual dobra a força do falado, não substitui.

**Conclusão: a fórmula completa é VISUAL (para) + PISTA FALSA (segura) + REVEAL (recompensa).** Pra isolar de vez, o teste é replicar a estrutura falada com e sem choque visual — o double down é a oportunidade.

### React como formato do double down (depoimento do Canadá)

**Vale testar, sim — e o react resolve o gancho visual naturalmente:** o print do depoimento NA TELA é o elemento visual que o formato falado sozinho não tem. Regras pro react funcionar dentro do padrão vencedor:
1. **Não entregar o print inteiro no primeiro frame** — print borrado/parcial ou virado é a pista falsa visual ("recebi uma mensagem do outro lado do mundo que quase me fez chorar")

4. Manter tensão de curiosidade na fala enquanto o print não abre
